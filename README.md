# DIYLevel 关卡排序

为 OC2DIYLevel 自定义关卡提供更方便的选关体验，兼容 DIYLevelFastInit。

## 功能

1. 退出自定义关卡后，自动回到上次的选关界面，恢复原关卡的焦点和排序，方便继续选择其他关卡。
2. 在上次选择的关卡及其所属关卡包前显示绿点。选择新关卡后，标记会更新，下次打开游戏仍可找到上次选择的关卡。
3. 关卡列表支持按名称或文件修改时间排序，可自由切换正序和倒序。两个下拉控件固定显示在菜单右侧，不随关卡列表滚动，所选设置会自动保存。
4. 关卡包和关卡右侧提供置顶按钮，并随菜单一起缩放。置顶项按置顶先后固定排列，不参与自动排序；安装 FastInit 时位于刷新按钮下方，否则位于列表最上方。再次点击可取消置顶，置顶记录会自动保存。

## 安装

需要《胡闹厨房 2》、BepInEx 5 和 OC2DIYLevel；DIYLevelFastInit 可选。

1. 从 [Releases](https://github.com/CH3NGYZ/Overcooked-2-DIYLevelSorting/releases) 下载 `OC2DIYLevelSorting.dll`。
2. 关闭游戏，将 DLL 放入游戏目录的 `BepInEx/plugins/`。升级时替换旧版同名文件。
3. 启动游戏，打开 DLC 的“更多关卡”，即可在右侧选择排序方式。

## 配置与说明

配置文件为 `BepInEx/config/com.ch3ngyz.plugin.diylevel.sorting.cfg`，首次加载插件后自动生成。

- 自动返回选关界面默认开启。在 `[Navigation]` 下设置 `ReturnToLevelList = false` 可以关闭。
- 自动返回仅在本次游戏中进入并退出自定义关卡后生效；关卡包已删除时返回关卡包列表。
- “添加时间”采用资源文件原修改时间：关卡包和包内关卡分别读取各自对应的文件时间。
- 名称排序使用当前菜单显示的名称。
- 绿点表示最近一次选择的关卡及其所属关卡包。
- 置顶只改变列表显示顺序，不影响原关卡选择和绿点记录。
